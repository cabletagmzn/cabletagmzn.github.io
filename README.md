# CableTag MZN

**ES ·** Programa gratuito para imprimir etiquetas de cables y de equipos desde Excel, Word o CSV, con un PDF que cuadra al milímetro con las hojas de etiquetas A4. Funciona sin internet. 23 idiomas.

**EN ·** Free tool to print cable and equipment labels from Excel, Word or CSV, producing a PDF that lines up to the millimetre with A4 label sheets. Works offline. 23 languages.
